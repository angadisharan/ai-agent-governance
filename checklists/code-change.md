# Code Change Checklist

- [ ] Task scope and acceptance criteria are clear.
- [ ] Only approved, permitted files were inspected.
- [ ] No hidden files, secrets, or restricted systems were accessed.
- [ ] Change is minimal and follows project architecture.
- [ ] Input validation and authorisation are correct.
- [ ] Tenant isolation is preserved and tested where applicable.
- [ ] Errors and logs do not expose sensitive data.
- [ ] Relevant tests were added or updated.
- [ ] Actual validation results are documented.
- [ ] Specifications and documentation are updated as needed.
- [ ] Remaining risks and skipped checks are disclosed.
