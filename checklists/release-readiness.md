# Release Readiness Checklist

- [ ] Requirements and release scope are approved.
- [ ] Architecture and security reviews are complete where required.
- [ ] Automated tests and contract checks passed, or exceptions are approved.
- [ ] Dependency, secret, and static-analysis checks were reviewed.
- [ ] Database migrations are reviewed and tested.
- [ ] Rollback/recovery plan is documented.
- [ ] Monitoring, alerts, and operational ownership are ready.
- [ ] Tenant isolation and regional configuration are verified where relevant.
- [ ] No secrets or prohibited data are included in artefacts.
- [ ] Deployment has explicit authorisation.
- [ ] Post-release verification and incident contacts are defined.
