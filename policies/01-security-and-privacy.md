# Security and Privacy Policy

## Mandatory controls

- Classify data before processing it; default to confidential when uncertain.
- Never read or expose secrets, credentials, private keys, session tokens, or production configuration.
- Use synthetic or approved sanitised data for development and tests.
- Do not send private data or code to external services without approval.
- Apply least privilege, secure defaults, input validation, output encoding, and safe error handling.
- Avoid logging secrets, tokens, payment data, or unnecessary personal information.
- Require explicit approval for changes to authentication, authorisation, encryption, retention, or access controls.
- Report accidental exposure without repeating the sensitive value.

## Privacy

Minimise collection, access, retention, and disclosure. Respect approved retention, deletion, consent, and data-residency requirements. Do not infer permission to use personal data from its availability.

## Verification

For security-sensitive changes, identify the threat, affected assets, trust boundaries, mitigations, and tests. Escalate unresolved high-impact risks.
