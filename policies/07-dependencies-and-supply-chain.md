# Dependencies and Supply Chain

- Prefer maintained dependencies with a clear purpose and compatible licence.
- Review direct and transitive dependency risks.
- Use lockfiles and reproducible versions where supported.
- Do not install packages, run remote install scripts, or execute downloaded code without appropriate authorisation.
- Never pipe remote content directly into a shell.
- Do not disable signature, integrity, vulnerability, or licence checks.
- Use approved package registries and dependency update processes.
- Run vulnerability and licence scanning through approved tooling.
- Document material additions, upgrades, licence obligations, and mitigations.
